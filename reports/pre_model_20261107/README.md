# 更换网络结构前的研究汇报

汇编日期：2026-11-07。主线为2026-10-29至11-05的干净配对正式实验，
附录回顾10-28/29旧配对探索。不包含stable_v1结构修改及其结果。

- `研究汇报_更换模型前.pptx`：12页汇报，文字可编辑，图表使用高分辨率图片；包含演讲备注。
- `研究汇报_更换模型前.pdf`：便于直接展示与分享。
- `研究总结.md`：逐页讲稿、正式结果表、解释边界和数据来源说明。
- `figures/`：9组图表的PNG与SVG版本，可单独插入其他报告。
- `experiment_metrics.csv`：11个正式实验的PSNR/SSIM/LPIPS，含去噪子测试集。
- `paired_effects.csv`：四个匹配消融内的差值；不同家族的差值不可累加。
- `sources.json`：43个原始JSON文件的相对路径及SHA256。
- `preview_*.png`：逐页预览。
- `build_report.py`：重建脚本，只读取实验JSON，不加载模型、不训练。

建议用10–15分钟汇报：协议1分钟、问题诊断2分钟、匹配消融3分钟、
统计与记忆机制3分钟、第四任务与结论2分钟。早期探索附录用于答疑。

注意：短程实验以单种子筛查为主，不宣称统计显著；旧任务验证仅用于诊断的组，
与用已见任务平均验证选模的回放组，不能直接排名。回放组合仅为诊断参考，
不是无回放正交LoRA方案。数据集、训练输出和源JSON未被修改。

在仓库根目录使用含matplotlib、numpy、python-pptx的系统Python运行：

```bash
python reports/pre_model_20261107/build_report.py
```
